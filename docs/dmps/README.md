# DMP and metadata documents

このディレクトリには、助成機関が研究者に作成および提出を要求する Data Management Plan（DMP）または研究データのメタデータ（Metadata）の様式が格納されています。

```
dmps/
├── amed-dmp.xlsx : AMED の DMP 様式
├── cfa-dmp.docx : CFA の DMP 様式
├── erca-dmp.xlsx : ERCA の DMP 様式
├── erca-metadata.xlsx : ERCA の Metadata 様式
├── jsps-dmp.xlsx : JSPS の DMP 様式
├── meti-dmp.xlsx : METI の DMP 様式
├── meti-metadata.xlsx : METI の の Metadata 様式
├── naro-dmp.xlsx : NARO の DMP 様式
├── nedo-dmp.xlsx : NEDO の DMP 様式
├── nedo-metadata.xlsx : NEDO の DMP 様式
└── nict-dmp.xlsx : NICT の DMP 様式
```
